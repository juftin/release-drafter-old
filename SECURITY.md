# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `v1` / `main` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please do **not** open a public issue.

Instead, please report it privately via GitHub Security Advisories or by emailing [juftybot@gmail.com](mailto:juftybot@gmail.com).

Please include:
- A description of the issue.
- Steps to reproduce or proof-of-concept.
- Potential impact.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
